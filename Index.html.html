Bulk import (paste, file, or link)
If a header row (Name, RA, Dec, Priority, Duration — any order) appears within the first few lines, columns are matched by name — a title row above it (e.g. a spreadsheet export banner) is fine and gets skipped automatically. Any extra column you add — "Remarks", "Comments", "Notes" — is ignored wherever it sits; put your own reference notes there freely. Add a "FixedStart" column (HH:MM, UT) to mark a row as a fixed-time event. Without a recognizable header anywhere near the top, the first five comma/tab-separated values per line are used positionally: Name, RA, Dec, Priority, Duration(min). Priority 1 (highest) – 5 (filler), 0 = Inactive.
The link must be shared/published as "anyone with the link can view" — this fetches it as CSV directly in your browser. If your browser blocks the request (CORS), use File → Share → Publish to web → CSV in Google Sheets and paste that link instead, or use the file picker above, which always works offline.
