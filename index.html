Bulk import (paste, file, or link)
If your first row is a header (Name, RA, Dec, Priority, Duration — any order), columns are matched by name and extra columns like "Remarks" are ignored wherever they sit. Without a header, the first five comma/tab-separated values per line are used positionally: Name, RA, Dec, Priority, Duration(min). Priority 1 (highest) – 5 (filler), 0 = Inactive.
The link must be shared/published as "anyone with the link can view" — this fetches it as CSV directly in your browser. If your browser blocks the request (CORS), use File → Share → Publish to web → CSV in Google Sheets and paste that link instead, or use the file picker above, which always works offline.
