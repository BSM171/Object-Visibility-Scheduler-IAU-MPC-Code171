# Object-Visibility-Scheduler-IAU-MPC-Code171
Flarestar Visibility &amp; Scheduling Console: a priority-weighted planner for a single observing night at Flarestar Observatory (Malta). Computes each target's visibility window, avoids meridian flips on GEM mounts, packs sectors back-to-back, and charts altitude dusk-to-dawn in GMT. Import via form, CSV, file, or sheet link.
